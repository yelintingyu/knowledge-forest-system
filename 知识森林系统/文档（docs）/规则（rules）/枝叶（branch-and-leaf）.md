# 枝叶生长规则

## 长叶（概念知识）
- 叶片是领域内**不断增加的概念知识**：一个概念一张叶（案例、工具、数据、心得、文献提炼）。
- 使用 `叶片模板（t-leaf）`：填写概念定义、我的理解、来源营养（文献/碎片）。
- 必须填写 `parent-node`，链接到树干概念（底层逻辑）或现有枝叶。
- 叶笔记可互相链接。

## 文献拆解为叶片（一文献多叶）
- **一份文献通常包含多个核心概念，可拆解为多片叶**——而不是一片叶装下整篇文献。
- 拆解流程：
  1. AI 分析文献，提取**核心概念清单**（通常是 3~10 个）；
  2. 每个核心概念建一片叶（`叶片模板（t-leaf）`），概念定义 + 我的理解；
  3. 每片叶的 `来源营养（文献）` 指向该文献（可链接到文献笔记或土壤中的原件）；
  4. 概念叶之间、概念叶与树干（底层逻辑）之间建立链接。
- 文献笔记（如 `XX-读书笔记`）可保留，作为**营养入口**和综合解读，但它不再是"一片叶"，而是多片概念叶的共同来源。
- 养分度量按概念叶计算（见下），概念越被引用，营养越高。

## 养分度量
- 每片叶子初始 `nutrition: 1`。
- 被其他笔记链接一次 +0.5（可由 Dataview 动态计算）。
- 枝条总养分 = 直属叶子营养值 + 子节点营养总和。

## 枝条检测
通过 Dataview 查询每个概念节点的入链数量和营养值，供开花时参考。
