# 枝叶生长规则

## 枝条（资料/文献笔记）
- **枝条 = 一份文献/资料笔记**（读书笔记、资料笔记、研究报告、课程笔记等），是**树干（底层逻辑）与叶片（概念知识）之间的中间层**。
- 每根枝条承载一份营养，从树干长出：`parent-node` 指向树干（`树干-领域名`），`type: branch`。
- 枝条用 `枝条模板（t-branch）` 创建，包含：原始内容、核心理解、拆解的概念叶、链接。
- 枝条是「一文献多叶」的组织单元：一份资料 → 一根枝条 → 多片概念叶。
- 枝条之间可互相嫁接（见嫁接规则），也可作为开花时的高优先养分来源。
- 以后所有资料类笔记（不限于读书笔记）统一归为枝条。

## 长叶（概念知识）
- 叶片是领域内**不断增加的概念知识**：一个概念一张叶（案例、工具、数据、心得、文献提炼）。
- 使用 `叶片模板（t-leaf）`：填写概念定义、我的理解、来源营养（文献/碎片）。
- **必须填写 `parent-node`，链接到所属枝条**（`XX-读书笔记`）或树干概念（底层逻辑）。
- 叶笔记可互相链接。

## 文献拆解为叶片（一文献多叶，挂在枝条上）
- **一份文献通常包含多个核心概念，可拆解为多片叶**——而不是一片叶装下整篇文献。
- 拆解流程：
  1. AI 分析文献，提取**核心概念清单**（通常是 3~10 个）；
  2. 文献笔记作为**枝条**创建（`枝条模板（t-branch）`，`type: branch`）；
  3. 每个核心概念建一片叶（`叶片模板（t-leaf）`），概念定义 + 我的理解，`parent-node` 指向该枝条；
  4. 每片叶的 `来源营养（文献）` 指向该枝条；概念叶之间、概念叶与树干（底层逻辑）之间建立链接。
- 枝条 = 多片概念叶的共同来源与挂载点；养分度量按概念叶计算（见下），概念越被引用，营养越高。

## 一枝条最少一叶（硬性要求）
- **每根枝条必须至少拆出 1 片概念叶**，不允许只有枝条没有叶片的"空枝条"。
- 建枝条时必须同步提炼 ≥1 个核心概念并创建概念叶（`parent-node` 指向该枝条）。
- 若某文献暂时提炼不出独立概念，至少要挂 1 片"文献总纲叶"（概括该文献的核心洞察）作为最低叶片。
- 枝条检测时，"待提炼"状态视为不合格，需立即补齐。

## 一一对应（领域 → 树干 → 枝条 → 叶片）
- **叶片是根据枝条长出来的**：每一片概念叶的 `parent-node` 必须指向**所属领域内的一根具体枝条**，实现 领域 → 树干 → 枝条 → 叶片 的严格一一对应。
- **不能 A 叶子长在 B 树上**：一片叶只能挂在自己领域、自己枝条上；枝条引用他枝条/他领域的叶片不算"长叶"，必须有自己的专属叶片。
- **叶片按当前领域优化**：同一概念在不同领域，叶片内容按该领域视角提炼（如《暗知识》在读书=知识论叶、在新媒体=AI 认知叶），不跨领域共用一片叶。
- **一枝条至少一叶，可多叶**：根据分析，一根枝条可拆 1~N 片概念叶；多根枝条不共享同一片叶作为"专属叶"（可互相链接引用，但各自必须有专属叶）。

## 抽细枝（Twig，枝条的分支组织层）
- **细枝是从枝条上抽出的子枝**：当一根枝条的叶片较多时，按主题/章节抽出细枝，叶片改挂细枝——层级为 树干 → 枝条 → 细枝 → 叶片。
- **触发条件**：枝条下叶片 **≥4 片**时按主题分组抽细枝；或文献有天然章节结构（书的分章/课程分模块）时，一章/一模块一根细枝。
- **细枝要求**：
  - `type: twig`，`parent-node` 指向所属枝条；放于 `枝条（branches）/` 目录，命名 `{枝条名}-细枝-{主题}`；
  - 内容：主题说明 + 挂载的叶片链接 + 组内逻辑；
  - 叶片 `parent-node` 指向细枝（严格模式）；一细枝 2~3 片为宜。
- **不强制**：叶片 ≤3 的枝条可不抽细枝，保持 枝条 → 叶片 两级。

## 养分度量
- 每片叶子初始 `nutrition: 1`。
- 被其他笔记链接一次 +0.5（可由 Dataview 动态计算）。
- 枝条总养分 = 直属叶子营养值 + 子节点营养总和。
