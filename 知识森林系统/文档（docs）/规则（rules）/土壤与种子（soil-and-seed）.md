# 土壤与种子规则

## 土壤（原始碎片信息）
- 所有未加工的信息（摘录、灵感、聊天记录、随手记）均视为**土壤**。
- 存放位置：`土壤（soil）` 文件夹或 Daily Notes。
- 不要求立即分类，保留原貌。
- 可选择性打上标签 `#soil` 以备检索。
- **土壤只增不删，保留原始性**。仅在极长期无链接且经人工确认后才移除。

## 种子（核心领域）
- 种子是**你自主确定的知识领域名称**，如“读书”“新媒体”“AI”“产品设计”“投资”等。它就是这棵树的身份标签。
- 种子笔记用 `#core-seed` 标签，`type: core-seed`，笔记标题即为领域名（如“读书”）。
- 可以**随时种、同时种多颗种子**。
- 创建种子时，允许对应文件夹为空（休眠期）。当土壤中出现与该领域相关的碎片、或你主动投入种子文献后，种子“发芽”，长出几何主干。

## 种子的生命周期
- **休眠期**：创建后无关联碎片、无树干，等待条件成熟。
- **发芽**：首次链接到土壤碎片或生成几何主干。
- **成树**：具备完整主干和枝叶，经历过至少一次开花。
- **分株**：当某根枝条的养分总量超过主干的 40%，且已独立开花，可考虑分离为新树（新领域种子）。
- **年轮日志**：每年年底，在种子笔记中更新一段“年轮”，记录当年关键生长（开花数、果实数、领域认知的演变）。

## 不建议合并
原则上不合并领域种子，保持细粒度有助于精确追踪不同知识领域。如需关联，可通过嫁接或双链连接。
