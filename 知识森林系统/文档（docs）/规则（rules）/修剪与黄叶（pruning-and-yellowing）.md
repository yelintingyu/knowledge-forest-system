# 修剪与黄叶规则

## 黄叶（自然老化）→ 落叶堆肥
- 一片叶子若连续 90 天未被引用，且链接数 ≤1，状态变为“黄”。
- Dataview 列出黄叶清单。
- 可手动激活（变绿），或“落叶”——打上 `#fallen-leaf`，移至 `堆肥（Compost）`。
- **堆肥 = 落叶堆肥**：存放降解的单片黄叶、被清理的孤立碎片——**提取摘要后存放，可删除原文件**。
- **堆肥可纳入土壤**：堆肥养分根据开花问题**适时激活**（即适时施肥）——开花时被检索到，即可重新作为养分。

## 修剪（主动裁枝）→ 枯枝仓库
- 整根枝条可被剪除，标注 `#pruned-branch` 及原因。
- 被剪除的枝条（结构化知识）移入 **`枯枝（Archive）`**，设置 `archived: true`。
- **枯枝 = 枯枝仓库**：被剪除的整根枝条**永久保留**，只是从日常视野隐藏，**以备将来可能的回溯**。

## 两者的区别（一句话）
- **堆肥（Compost）= 落叶堆肥**：单片黄叶/孤立碎片，提取摘要后删原文件，最终化为养分（施肥）。
- **枯枝（Archive）= 枯枝仓库**：整根剪下的枝条，完整保留、隐藏视野，为将来回溯留档。
