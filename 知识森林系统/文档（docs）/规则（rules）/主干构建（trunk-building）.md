# 几何主干构建规则

## 何时建立
当你需要系统学习一个领域，并找到一篇“定义性”长文时。

## 构建步骤
1. 复制模板 `几何主干模板（t-geometric-trunk）`，重命名为 `树-领域名`。
2. 将种子文献全文提供给 Work Buddy，使用提示词 `提示词（prompts）/生成主干（generate-trunk）.md`。
3. 将 AI 返回的“知识几何体”粘贴到笔记中，包括概念层级、因果链、Mermaid 图。
4. 为每个核心概念创建独立笔记，并在主干中双链。
5. Frontmatter 设置：`type: trunk`, `domain: 领域`, `seeds: [关联种子]`。

## 主干要求
- 逻辑闭环，概念间有明确的有向链接。
- 包含至少一个 Mermaid 图（概念图、流程图）。
- 作为该领域所有枝叶的吸附中心。
