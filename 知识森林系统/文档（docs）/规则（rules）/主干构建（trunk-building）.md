# 树干构建规则

## 核心思想（概念升级 v2.4）
- **种子是领域**：种子即大树的名字（如“读书”“新媒体”），是根系、树干、叶片、开花、结果的集合，**不是具体文献**。
- **树干 = 不断增加的底层逻辑**：基石、原则、规律、核心概念框架，随营养持续追加。
- **文献 = 营养**：任何与领域相关的文献/碎片都是养分。AI 分析文献与该领域的相关性，相关则建立链接；并从营养中提炼可沉淀的底层逻辑，追加到树干。

## 何时立干
当你确定一个领域种子（如“读书”）时，即用 `树干模板（t-trunk）` 立干；不需要等某篇“定义性长文”。

## 立干步骤
1. 复制模板 `树干模板（t-trunk）`，重命名为 `树干-领域名`（如 `树干-读书`）。
2. 填写**领域基石**（该领域不证自明的前提）。
3. 后续动作由营养驱动：
   - 新文献投入 `土壤（soil）` 后，AI 分析其与该领域的相关性；
   - 相关 → 建立**枝条**（文献笔记，`枝条模板（t-branch）`），从树干长出；
   - 枝条内部拆解为多片概念叶（见枝叶规则）；
   - 同时提炼底层逻辑**追加**到树干（编号管理）。

## 两种触发机制（重要）

### 机制一：土壤新增文件 → 全领域扫描更新
- 每次土壤新增文件，AI **分析后扫描所有已有领域**，对**所有相关领域**进行更新：
  - 相关领域的树干（底层逻辑追加）、枝条（建新枝）、概念叶（拆新叶）同步更新；
  - 一份文献可同时触发多个领域的更新（多对多营养）。

### 机制二：新增领域 → 全土壤扫描建链
- 新领域立干后，AI **扫描全部已有土壤文献**，根据分析把相关文献**建链到新领域**，并：
  - 为新领域生成树干（提炼**该领域视角**的底层逻辑）；
  - 抽枝生叶：把相关文献建为新领域的枝条，拆出该领域视角的概念叶；
- **关键：结合该领域进行优化，不照搬其他领域的枝条/概念**——同一文献在不同领域提炼的营养不同（如《暗知识》在读书=知识论、在新媒体=AI创作）。

## 几何主干的定位（可选工具）
- 当领域出现**核心文献**时，可复制 `几何主干模板（t-geometric-trunk）` 做一次深度几何化解构（概念层级、因果链、Mermaid 图）。
- 解构结果**并入**树干（作为底层逻辑的阶段性输入），而非替代树干。

## 树干要求
- 底层逻辑条目需逻辑闭环、可不断追加；建议每条标注来源营养（文献）。
- 树干是该领域所有枝叶的吸附中心；叶片链接回树干概念。

## Frontmatter
- `type: trunk`, `domain: 领域`, `seeds: [关联种子]`
