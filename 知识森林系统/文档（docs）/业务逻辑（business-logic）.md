## 1. 系统定位

知识森林系统是一个**以「领域」为单位、以文献为营养、以 AI 为园丁助手的个人知识自生长系统**。

- **不是**文件管理工具——而是让知识像森林一样自然生长的生态系统。
- 核心主张：种子是领域，文献是营养，知识在链接中自组织生长。
- 最终形态：多领域并立、根系互联的**知识生态森林**（嫁接=跨领域杂交；授粉=协作共享，未来规划）。

## 2. 核心概念

| 概念 | 定义 |
|---|---|
| **土壤（soil）** | 原始信息仓库（PDF/EPUB/口播/碎片），只增不删，保留原始性 |
| **种子（领域）** | 一棵大树的名字，如 读书、新媒体；决定树的生长方向 |
| **树干（trunk）** | 领域不断增加的**底层逻辑**（基石、原则、规律），编号管理 |
| **枝条（branch）** | 一份文献/素材的笔记（一素材一枝条，默认单条处理） |
| **细枝（twig）** | 枝条内部按主题/章节抽出的子枝（叶片 ≥4 时触发） |
| **叶片（leaf）** | 一个概念知识（一概念一叶，挂在所属枝条/细枝上） |
| **开花** | 遇问题，AI 从根系调取养分生成多方案 |
| **果实（Fruits）** | 实践结果：大果（AI 定 4 判定标准）/小果（直接答案），好坏都反哺土壤 |
| **堆肥（Compost）** | 落叶堆肥：单片黄叶/孤立碎片，提取摘要后存放，可删原文件，开花时适时施肥 |
| **枯枝（Archive）** | 枯枝仓库：被剪整枝永久保留、隐藏视野，供将来回溯 |

## 3. 层级结构（严格一一对应）

```
领域种子（读书 / 新媒体 / …）
 └─ 树干（底层逻辑）
     └─ 枝条（文献笔记，一素材一枝条）
         ├─ 细枝（主题组/章节，叶片 ≥4 时按需抽出）
         │   └─ 叶片（概念，一概念一叶）
         └─ 叶片（概念；≤3 片时不抽细枝，直接挂枝条）
```

- **叶片是根据枝条长出来的**：`parent-node` 必须指向所属领域内的具体枝条/细枝。
- **不能 A 叶子长在 B 树上**：不跨领域共享叶片；多枝可互链引用，但各有专属叶。
- **叶片按当前领域视角优化**：同一概念在不同领域各自成叶（如《暗知识》在读书=知识论叶、在新媒体=AI 认知叶）。
- **一枝条最少一叶**，可多叶；细枝一叶不挂、≥4 才抽。

## 5. 营养关系（多对多 + 交叉供给）

- **文献 ↔ 领域 是多对多**：一份文献含多种营养，可**交错供给多个领域**（枝条标注「可滋养：[[领域]]」）；一个领域需要多份营养。
- **交叉建链的配套动作**：枝条交叉后，**目标领域树干必须同步追加相应底层逻辑**（除非已存在重复）。
- 根系是菌根网络：同一碎片可同时滋养多棵树，开花时从全网络调取养分。

## 6. 生命周期（生长循环六步）

```
蓄土（文献入土壤）→ 生根长枝（AI 分析相关性、建枝条）→ 长干展叶（底层逻辑入树干、概念成叶）
→ 开花（问题驱动多方案）→ 结果复盘（实践评定）→ 反哺（果实回土壤、教训沉淀）
```

- **人机分工**：AI 做分析相关性、拆概念、提炼逻辑、生成方案；你定领域、选方案、评果实、修剪嫁接；系统做双链自组织、养分计量。
- **养分度量**：叶片初始 `nutrition: 1`，被引用 +0.5；枝条养分 = 直属叶 + 子节点总和。

## 7. 两种触发机制（系统运作核心）

### 机制一：土壤新增文件 → 全领域扫描更新
- 每次土壤新增文件，AI 分析后扫描**所有已有领域**，对**所有相关领域**同步更新——树干底层逻辑、枝条、概念叶。
- 一份文献可同时触发多个领域更新。

### 机制二：新增领域 → 全土壤扫描建链
- 新领域立干后，扫描**全部已有土壤文献**，相关文献建链到新领域，生成该领域视角的树干、抽枝生叶。
- **结合该领域优化，不照搬其他领域**（同一文献在不同领域提炼的营养不同）。

## 8. 规则体系（9 条规则）

| 规则 | 核心内容 |
|---|---|
| 土壤与种子 | 土壤只增不删；种子=领域，决定深耕方向 |
| 根系系统 | 营养多对多；两种触发机制；AI 分析相关性建链 |
| 养分浓度 | 链接数=营养；概念越被引用营养越高 |
| 主干构建 | 树干=底层逻辑持续追加；两种触发机制 |
| 枝叶生长 | 一素材一枝条；一概念一叶；一枝条最少一叶；一一对应；抽细枝 |
| 开花 | 问题驱动，AI 调取养分生成多方案 |
| 嫁接 | 跨领域杂交创新，可行性评估后建立链接 |
| 修剪与黄叶 | 黄叶→落叶堆肥（提取摘要后可删原文件）；剪枝→枯枝仓库（永久保留隐藏） |
| 结果与反哺 | 大果 AI 定 4 判定标准；好果模式回树干，坏果教训回土壤 |

## 9. 标准操作流程（11 条标准指令）

| 类别 | 指令 |
|---|---|
| 基础 | ① 扫描土壤并建链 ② 文献接入（一文献多叶，≥4 叶抽细枝） ③ 盘点领域状态 |
| 生长 | ④ 立干/长枝条（含机制二全土壤扫描） ⑤ 展叶 ⑥ 开花 ⑦ 结果与复盘 ⑧ 嫁接 |
| 维护 | ⑨ 修剪与黄叶 ⑩ 归档（枯枝） ⑪ 生态盘点/年轮 |

## 10. 执行铁律

1. **只增不删**：土壤保留原始性；任何删除/移动前先列清单，经确认后执行。
2. **一概念一叶**：概念独立成叶，不堆叠。
3. **一素材一枝条（默认单条处理）**：不合并，除非明确提示"合并"。
4. **一枝条最少一叶**：不允许空枝条；叶片一一对应所属枝条/细枝。
5. **全部建链**：原始文件 ↔ 枝条/细枝 ↔ 概念叶 ↔ 树干 全闭合。
6. **同步更新**：结构调整后同步相关文档与 log.md（副本为分发模板时保持纯净）。
7. **确认制**：重大操作（改名、移动、删除、归档）先说明影响范围，再执行。
