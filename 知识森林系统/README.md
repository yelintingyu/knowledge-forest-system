# 🌳 知识森林系统 (Knowledge Forest) v2.3

> 以**原始碎片为土壤**，以**自主确定的领域为种子**（如“读书”“新媒体”“AI”），用**根系网络吸取养分**，长出**几何主干**，通过**多花绽放、大小果分级**实现知识自生长的生命系统。

## 核心理念
- **土壤**：所有未加工的信息（摘录、灵感、日记等）是肥沃的土壤，只增不删，保留原始性。
- **种子**：一个**你自主确定的领域名称**（如“读书”“新媒体”“AI”），决定了一棵树所代表的知识领域。
- **根系**：双链与标签构成的连接网络，从土壤中有选择地吸收特定养分。同一碎片可滋养多棵树。
- **树干**：AI 解构一篇经典文献后形成的几何知识图谱。
- **枝叶**：日常积累的案例、工具、心得，附着在树干概念上。
- **开花**：面对真实问题，AI 调取根系吸收的养分，碰撞出多个候选解法。可要求生成“沙盒测试”。
- **果实**：实践后评出**大果（项目/任务，AI 动态生成 4 个判定标准）** 和**小果（直接答案，人为判定好/坏）**。
- **反哺**：果实分解回土壤，成为新一轮生长的养分。

## 隐喻对应表

| 自然隐喻 | 系统功能 | Obsidian 实现 |
|---------|----------|----------------|
| 土壤 | 原始碎片信息 | `土壤（soil）` 或 Daily Notes，带 `#soil` 标签 |
| 种子 | 领域标签（如“读书”） | `#core-seed` 笔记，可休眠 |
| 根系 | 链接网络 | 双链、Dataview 统计吸收量 |
| 树干 | 几何知识主干 | MOC笔记 + Mermaid 图 |
| 枝叶 | 扩展知识 | 链接到树干概念的子笔记 |
| 开花 | 生成多个解法 | `花-` 笔记，由 Work Buddy 创建 |
| 嫁接 | 跨界创新 | `嫁接-` 笔记，需通过可行性评估 |
| 大果 | 项目/任务结果 | AI 生成 4 个判定标准，四级评定 |
| 小果 | 直接答案结果 | 人为判定好/坏 |
| 反哺 | 果实化为新养分 | 写回土壤碎片或种子日志 |

## 快速开始
1. 安装 [Obsidian](https://obsidian.md)，启用插件：**Dataview**、**Templater**、**Local REST API**（可选）。
2. 将本仓库作为你的 Obsidian Vault 或复制文件到现有 Vault。
3. 阅读 `文档（docs）/搭建指南（setup-guide）.md` 完成配置。
4. 播下第一颗种子：用 `种子模板（t-core-seed）` 创建一个你关注的领域（例如“读书”）。
5. 种树：用 `几何主干模板（t-geometric-trunk）` 构建树干，搭配 Work Buddy 生成几何主干。
6. 开花：用 `问题模板（t-question）` 写下问题，触发 Work Buddy 生成多朵花。
